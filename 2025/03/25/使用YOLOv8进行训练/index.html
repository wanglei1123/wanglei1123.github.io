本次试验为阿里云服务器，系统版本为Ubuntu 24.04 64位

一、安装Anaconda

步骤 1：下载 Anaconda 安装包

打开终端 (Ctrl + Alt + T)。

使用 wget 命令下载最新的 Anaconda 安装包：

wget https://repo.anaconda.com/archive/Anaconda3-2024.06-1-Linux-x86_64.sh

步骤 2：验证安装包完整性（可选）

下载完成后，可以通过以下命令检查 SHA-256 校验和，确保文件完整性：

sha256sum Miniconda3-latest-Linux-x86_64.sh

然后前往 Anaconda官网 查看官方的校验和进行比对。

步骤 3：运行安装程序

为安装包赋予执行权限：

chmod +x Miniconda3-latest-Linux-x86_64.sh

运行安装程序：

./Miniconda3-latest-Linux-x86_64.sh

根据提示完成安装：

阅读许可协议，按 Enter 键滚动，并输入 yes 接受。

选择安装路径（推荐默认路径 ~/miniconda3 或 ~/anaconda3）。

是否初始化 Conda？选择 yes。

步骤 4：激活 Anaconda

安装完成后，需要激活 Conda。执行以下命令：

source ~/.bashrc

验证安装是否成功：

conda –version

如果显示类似 conda 24.x.x 的版本号，则表示 Anaconda 已成功安装。

步骤 5：使用 Conda 管理环境

以下是一些常用的 Conda 命令：

更新 Conda：

conda update -n base -c defaults conda

创建新环境：

conda create -n myenv python=3.11

激活环境：

conda activate myenv

退出环境：

conda deactivate
