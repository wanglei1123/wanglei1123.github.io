YOLOV8笔记

写在前面

  • backbaone: 主干网络，用来提取特征，常用VGG
  • head: 获取网络输出，利用提取特征做出预测
  • neck：放在backbone和head之间，进一步提升特征的多样性及鲁棒性

YOLOv8简介

​YOLOv8网络模型于2023年被提出，相较于之前版本其精度等相关指标均有明显的提升。YOLOv8网络模型如图 1 所示，主要有输入、主干(Backbone)、颈部(Neck)和头部(Head)4部分组成。Backbone部分由5个卷积模块，4个特征融合模块(CSP bottleneck with 2 convolutions, C2f)和1个快速-空间金字塔池化层(spatial pyramid pooling-fast, SPPF)组成。相比于之前的版本，YOLOv8使用C2f模块代替卷积神经网络模块(concentrated-comprehensive convolution block, C3)，使其收敛的速度和效果都得到显著的提升。Neck部分采用是路径聚合网络(path aggregation network,PANet)，与特征金字塔网络 (feature pyramid network, FPN)单向传递不同，PANet是一个双向通路网络，使得顶层更容易接收到底层的信息。Head部分为解耦头结构，对回归与预测分支进行了分离。同时在Yolov8网络模型中采用了完全交并比(complete intersection overunion, CIoU)和分布焦点损失(distributional feature loss, DFL)等新的损失函数替代原有的损失函数, 实现了更有效的学习和收敛。

YOLOv8整体结构

YOLOv8 的整体结构主要分为以下四个部分：

1. Backbone（骨干网络）

作用：从输入图像中提取多尺度特征。

主要模块：

  • Focus：下采样并提取局部特征。
  • Conv：卷积层（Conv + BN + SiLU）。
  • C2f：改进版特征提取模块，提高特征复用能力。
  • SPP（Spatial Pyramid Pooling）：空间金字塔池化，扩大感受野。

特点：

  • 高效特征提取
  • 多尺度信息保留

2. Neck（颈部网络）

作用：融合和增强不同尺度的特征，帮助检测头更精确地识别物体。

主要模块：

  • C2f：进一步特征提取和融合。
  • PAN（Path Aggregation Network）：通过上下采样，实现多层特征融合。
  • Upsample 和 Concat：进行特征拼接。

特点：

  • 融合高层和低层特征
  • 保持空间细节

3. Head（检测头）

作用：执行目标检测任务，预测边界框和分类结果。

主要模块：

  • C2f：进一步特征提取。
  • Detect：输出目标的位置、置信度和类别。相比于YOLOv5或YOLOv6，YOLOv8则是使用了Decoupled-Head，同时由于使用了DFL 的思想，因此回归头的通道数也变成了4*reg_max的形式
  • Anchor-Free：无需预定义的锚框，直接预测目标框中心点和尺寸。虽然v8的CIOU使用方式与v5保持一致，但引入Anchor-Free的Center-based methods(基于中心点)后，模型从输出“锚框大小偏移量(offest)”变为”预测目标框左、上、右、下边框距目标中心点的距离(ltrb = left, top, right, bottom)”。

特点：

  • 提高检测精度
  • 减少计算量

4. Loss（损失函数）

作用：评估模型的预测结果与真实标签之间的差距，优化训练过程。

主要组成：

  • CIoU Loss：用于边界框回归，计算真实框和预测框的距离。
  • Focal Loss：用于分类任务，解决类别不平衡问题。
  • BCE Loss：用于置信度预测。

特点：

  • 更稳定的边界框回归
  • 处理类别不平衡问题

各模块介绍

1. c2f模块

在 YOLOv8 中，C2f（Cross-Stage Partial Fusion） 模块是一种改进的特征提取模块，它在模型中起着高效特征提取和融合的作用。它是从 YOLOv5 的 C3 模块演变而来的，结合了 CSPNet（Cross-Stage Partial Network）和更高效的特征融合方法。

先看一下C3模块的结构图，然后再对比与C2f的具体的区别。如下图所示，针对C3模块，其主要是借助CSPNet提取分流的思想，同时结合残差结构的思想，设计了所谓的C3 Block，这里的CSP主分支梯度模块为BottleNeck模块，也就是所谓的残差模块。同时堆叠的个数由参数n来进行控制，也就是说不同规模的模型，n的值是有变化的。

其实这里的梯度流主分支，可以是任何之前你学习过的模块，比如，美团提出的YOLOv6中就是用来重参模块RepVGGBlock来替换BottleNeck Block来作为主要的梯度流分支，而百度提出的PP-YOLOE则是使用了RepResNet-Block来替换BottleNeck Block来作为主要的梯度流分支。而YOLOv7则是使用了ELAN Block来替换BottleNeck Block来作为主要的梯度流分支。

对于cv1卷积和cv2卷积的通道数是一致的，而cv3的输入通道数是前者的2倍，因为cv3的输入是由主梯度流分支（BottleNeck分支）依旧次梯度流分支（CBS，cv2分支）cat得到的，因此是2倍的通道数，而输出则是一样的。通过C3模块的结构图可以看到，C3模块和名字思路一致，在模块中使用了3个卷积模块（Conv+BN+SiLU），以及n个BottleNeck。

下面就简单说一下C2f模块，其结构如下图所示。我们可以很容易的看出，C2f模块就是参考了C3模块以及ELAN的思想进行的设计，让YOLOv8可以在保证轻量化的同时获得更加丰富的梯度流信息。

2. SPP模块

在 YOLOv8 中，SPPF 模块（Spatial Pyramid Pooling，空间金字塔池化） 是一种用于增强特征的模块。它通过多尺度的池化操作提取丰富的上下文信息，从而提升模型的检测精度。

而SPPF和SPP的区别就是，他没有把池化放到不同大小池化窗口的池化层来用，而是只用一个5*5的池化窗口，进行了3次池化，然后进行拼接。

4.损失函数

对于YOLOv8，其分类损失为VFL Loss（Varifocal Loss），其回归损失为CIOU Loss(Complete IoU Loss)+DFL(Distribution Focal Loss)的形式，这里Reg_max默认为16。

YOLOv8 VFL Loss 和 Focal Loss 的区别

核心思想对比

特点 Focal Loss VFL Loss
目标 解决类别不平衡，降低负样本的影响。 解决类别不平衡，同时提升正样本的置信度预测准确性。
加权策略 通过调节参数降低简单样本的损失权重，重点关注困难样本。 非对称加权，对正样本和负样本采用不同的加权方式，更关注主正样本。
置信度优化 仅关注类别预测结果，不考虑预测置信度的准确性。 同时优化类别置信度和边界框质量，提升预测置信度的可靠性。
适用场景 更适合多分类任务和单纯的目标检测。 更适合带有置信度预测的检测任务，例如 YOLOv8 中的目标检测。

📌 1. Focal Loss

Focal Loss 是对传统的交叉熵损失的改进，通过增加调节系数来减少易分类样本的损失权重，使模型更加关注难以分类的样本。

公式如下：

$$
FL(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)
$$

  • ( p_t )：模型预测的置信度。
  • ( \alpha_t )：类别平衡参数。
  • ( \gamma )：调节因子，用于控制易分类样本的损失。
  • 当 ( \gamma = 0 ) 时，退化为普通的交叉熵损失。

📌 2. VFL Loss

VFL Loss 进一步改进了 Focal Loss，通过非对称加权的方式对正样本和负样本进行不同的处理。

公式如下：

[
L_{VFL}(p, q) =
\begin{cases}

  • q \log(p) & \text{if 正样本} \

  • \alpha (1 - p)^\gamma \log(p) & \text{if 负样本}
    \end{cases}
    ]

  • ( p )：预测置信度。

  • ( q )：标签置信度，对正样本为真实框和预测框的 IoU，对负样本为 0。

  • ( \alpha ) 和 ( \gamma )：分别是负样本加权和调节因子。

特点：

  • 对正样本，VFL 使用实际的 IoU 作为目标置信度，引导模型学习真实置信度。
  • 对负样本，使用 Focal Loss 的形式降低容易分类样本的损失。

主要区别

区别点 Focal Loss VFL Loss
加权方式 对正负样本采用相同的 Focal Loss 加权方式。 非对称加权，对正样本和负样本采用不同处理方式。
正样本处理 仅优化类别预测，不考虑预测置信度的准确性。 使用 IoU 作为正样本的目标置信度，优化预测置信度的准确性。
负样本处理 通过 Focal Loss 降低负样本的损失权重。 使用传统 Focal Loss 方式对负样本进行加权。
训练收敛速度 训练速度较慢，特别是对于高置信度样本的优化。 更快收敛，对高置信度样本的优化更加有效。
适用场景 适用于目标类别多且正负样本极度不平衡的场景。 适用于需要精确置信度预测的场景，如 YOLOv8。

CIoU Loss

CIOU Loss 是一种改进的 IoU (Intersection over Union) 损失函数，相比传统的 IoU Loss、GIoU Loss 和 DIoU Loss，它不仅考虑了边界框的重叠程度，还引入了中心点距离和宽高比的惩罚项，优化边界框的定位精度。
